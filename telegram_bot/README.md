## 🛠️ آلية التخزين الرقمي السحابي (Cloud Media Harvester)
1. يعتبر البوت "المخزن الرقمي" قاعدة بيانات ومخزن وسائط سحابي مباشر.
2. بمجرد رفع أي ميديا (فيديوهات، ملفات PDF دراسية، صوتيات أذان وأذكار وتلاوات، أو صور ملخصات) داخل القناة أو في المحادثة المباشرة:
   - يستخرج البوت فوراً: `file_id`, `file_unique_id`, `file_type`, `file_name`, `file_size`, `mime_type`, `caption`, والتصنيف التلقائي (`quran`, `azkar`, `adhan`, `study`, `pdf`).
   - يتم حفظ البيانات في جدول `cloud_storage` داخل `users.db`.
   - يمكن للطلاب البحث واستعراض وتحميل المواد عبر أوامر `/storage`, `/search`, `/pdf`, إلخ.

## 🚀 تشغيل البوت

### الخيار 1: عبر Cloudflare Worker (24/7 مجاناً بالكامل دون جهاز محلي) — الخيار الموصى به
انظر تفاصيل مجلد `worker/` ودليل `worker/README.md`.

### الخيار 2: عبر Python (Webhook أو Polling محلي)

```bash
# 1. تثبيت الحزم المطلوبة
pip install -r requirements.txt

# 2. تعيين المتغيرات السرية
export TELEGRAM_BOT_TOKEN="your_bot_token_from_botfather"
export TELEGRAM_SECRET_TOKEN="your_webhook_secret_token"
# export WEBHOOK_URL="https://your-domain.com" # اختياري لوضع الـ Webhook

# 3. تشغيل البوت
python bot.py
```
